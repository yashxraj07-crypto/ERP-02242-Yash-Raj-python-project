Python To-Do List Application

About the Project

This is a simple Python-based To-Do List Application developed as part of my Python programming assignment.

It helps users manage their daily tasks and keeps track of task completion status.

Features

- Add and manage tasks
- View saved tasks
- Track task status (Pending/Done)
- Store tasks in a text file
- Automatically load previously saved tasks

Technologies Used

- Python
- Lists
- Functions
- Loops
- File Handling
- OS Module

Project Structure

├── project_to_do_list.py

How to Run

1. Install Python 3.
2. Clone or download this repository.
3. Open the project folder in VS Code.
4. Run the following command:

python3 project_to_do_list.py

Data Storage

The application stores tasks in a text file named "todo.txt", allowing previously saved tasks to be loaded when the application starts.
